## Recommendations
Recommendations, related to controls and/or compliance needs, that your IT manager could communicate to stakeholders to reduce risks to assets and improve Botium Toys’ security posture.

- Implement **Least Privilege** for org users as well as a **Separation of Duties**  
- Use **Encryption** to keep customer sensitive info secure in transit  
- Install **IDS** tool to detect and prevent unwanted traffic  
- Implement best practices for **Password Policies** and **Password Management**  
- Schedule **regular legacy system maintenance** and clearly define intervention methods  
- Create a **Disaster Recovery plan** and establish **Backups**
