## 🎯 Learning Objectives

By the end of the program, students should be able to:

- Understand core cybersecurity concepts, including the **CIA Triad**
- Identify common **threats, vulnerabilities, and risks**
- Apply **security controls** to protect organizational assets
- Conduct basic **risk assessments** and security audits
- Understand key frameworks and regulations such as **NIST, PCI DSS, GDPR, and SOC**
- Analyze security events using **logs, SIEM tools, and playbooks**
- Explain **incident response** and risk mitigation processes
- Understand authentication, authorization, encryption, and access control concepts
- Develop foundational skills for entry-level cybersecurity roles
- Prepare for the **CompTIA Security+** certification exam
